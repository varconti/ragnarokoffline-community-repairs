# crowded-world

Optional population-density preset with the stock 13 class profiles.

Copy this directory into your installation's `state/mods` folder. Enable it in Settings > Mods and apply the change. Disable it and apply again to restore the stock configuration. Back up your configuration first. It is optional and does not belong in the default game balance.

Validation is structural; no new gameplay balancing or audiovisual acceptance was performed for this public package.
