# Local mod inventory

This inventory distinguishes resource repairs, reusable code/configuration, and custom progression. It does not claim that every local mod is an installable English release. Original authors retain credit; stock pack names are not presented as newly created work.

| Mod | Purpose | Public material |
|---|---|---|
| `bot-balance-pilot` | Route population preset; requires the custom combat policy and class profiles. Not a standalone fix for the stock engine. | inventory only; integration or full English UI port required |
| `builder` | Optional PvM progression and endgame equipment scripts. Custom economy and progression; full English UI port is not published. | English recovery recipes |
| `builder-item-visuals` | Persistent item-name, icon, illustration and weapon-view overrides. Source resources stay user supplied. | English recovery recipes |
| `client-compatibility` | Repair enum mismatches in pet, random-option and footprint metadata. Binary game tables are not distributed. | English recovery recipes |
| `common-npcs` | Stock common NPC pack with local job/companion fixes; distinguish local changes from the original authors work. | inventory only; integration or full English UI port required |
| `crowded-world` | Optional population-density preset with the stock 13 class profiles. | English source mod |
